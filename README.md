# QuickNotes

QuickNotes is a lightweight note-taking web app that helps you capture and organise thoughts by category. Notes are saved in your browser, so they are still there when you return.

## Features

- Add notes under Personal, Work or Study.
- Search notes by text without regard to letter case.
- Delete individual notes or clear all notes after confirming.
- See a live note count and a readable creation date and time.
- Get clear validation when a note is empty or longer than 200 characters.
- Keep notes between visits with browser local storage.
- Use the responsive layout on desktop and small screens.

## Run locally

1. Download or clone this repository.
2. Open `index.html` in a modern web browser.
3. Add a note, choose its category and use the search field to find it later.

No build step or package installation is required.

## What I learned

- How semantic HTML and correctly connected form labels improve structure and accessibility.
- How Flexbox, category classes and a media query can make an interface readable across screen sizes.
- How to render user-provided text safely with DOM methods and `textContent`.
- How to manage an array of note objects, validate input and implement search and deletion.
- How JSON and local storage can preserve app data in the browser.
